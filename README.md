# EcoBuddy-AI-Brand-Identity
EcoBuddy is an AI-assisted brand identity project for a fictional eco-friendly startup that promotes reusable products such as water bottles, cloth bags, and bamboo toothbrushes. This project includes brand naming, logo concepts, colour palette, tagline, marketing content, and brand guidelines.
